CAMPOS MATERIALES

Reinaldo Chong desarrolló bajo el nombre Kusari una plataforma web interna para la exposición Campos Materiales.

La plataforma registró usuarios y más de 600 maquetas de una entrega semestral. Cada modelo recibió un código para apoyar su revisión y selección mediante concurso. Tras confirmarse la selección, el equipo curatorial y sus asistentes podían consultar fotografías y datos mediante interfaces diferenciadas.

El repositorio público rxiechong/ingresocmeauv corrobora que fue una aplicación full-stack para gestionar inscripciones a Campos Materiales. La cifra de registros y el flujo interno detallado son declaraciones primarias.
